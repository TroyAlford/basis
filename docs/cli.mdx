# CLI

`basis/cli` is the `basis` command. It supplies repository tooling without requiring consumers to assemble the underlying ESLint, Stylelint, Markdown, TypeScript, or documentation stacks.

```bash
bunx basis lint
bunx basis format
bunx basis typecheck
bunx basis check
bunx basis compliance
bunx basis doctor
bunx basis docs check
bunx basis docs build
```

- `lint` reports the full Basis policy through Bun's built-in linter.
- `format` applies every autofix the policy supports through the same native linter.
- `typecheck` runs Bun's built-in TypeScript checker; it requires Bun 1.4.3 or newer.
- `check` runs the repository's validation set.
- `compliance` runs the class-based architecture rule in a focused, report-only configuration.
- `doctor` verifies the installed consumer/runtime setup.
- `docs check` validates a docs tree; `docs build` writes the static documentation site.

`basis lint` and `basis format` require the first stable Bun release that ships `bun lint`; stable 1.4.4 does not include it.

The CLI is a facade over the same code and policy exported through `basis/eslint`, `basis/stylelint`, `basis/markdown`, and `basis/tsconfig/*`. It does not replace repository-specific scripts or add a second configuration system.
