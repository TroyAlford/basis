# Basis documentation

Basis is a Bun-first monorepo for class-based React UI, the Basis application server, configuration, logging, OAuth, testing, review policy, and repository tooling. It is consumed as a pinned Git dependency, not from npm.

```bash
bun add --dev --trust github:TroyAlford/basis#vX.Y.Z
```

## Why this shape

Basis optimizes for working software first, then for code that stays readable and maintainable. The monorepo bundles the runtime, UI, testing, and review surfaces because they share one owner and one release: a consumer pins one Git tag instead of coordinating a matrix of independently versioned packages.

The architecture favors emergent reuse over speculative abstraction, one authoritative owner over duplicate registries, and local repository idiom over fashionable layers. The same philosophy becomes the small, versioned reviewer policies used to review changes. Read [Engineering Principles](./engineering-principles.mdx) for the full reasoning behind correctness, simplicity, ownership, test confidence, and architectural judgment.
