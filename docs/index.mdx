# Basis documentation

Basis is a Bun-first monorepo for class-based React UI, the Basis application server, configuration, logging, OAuth, testing, review policy, and repository tooling. It is consumed as a pinned Git dependency, not from npm.

```bash
bun add --dev --trust github:TroyAlford/basis#vX.Y.Z
```

This site is the authoritative reference for the monorepo. Root and package READMEs are concise entry points; use the sections below for package contracts and usage.
