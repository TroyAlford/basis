# Utilities

`basis/utilities` is the supported consumer surface for shared deterministic primitives. Internal Basis packages continue to import the workspace directly; applications use the `basis/utilities` facade.

## String and naming

`kebabCase`, `pascalCase`, `snakeCase`, `titleCase`, `deburr`, `unique`, and `classNames` handle common naming and class composition. `dataAttributes` and `classNames` are used heavily by the React component hierarchy.

```ts
kebabCase('MoonPhase') // 'moon-phase'
titleCase('model-first database') // 'Model First Database'
```

## Numbers, time, and bytes

`clamp`, `formatBytes`, `formatMilliseconds`, `formatNumber`, `parseMilliseconds`, and `Milliseconds` cover bounded values and display formatting. `getLocale` resolves the active locale.

## Objects and paths

`clone`, `deepEquals`, `get`, `set`, `isNil`, and `isRefObject` provide small object/path primitives. `sortBy` provides stable typed sorting. The internal `merge` helper used by Basis components is not exported from the public index.

## Async and identity

`AbortablePromise` provides cancellation-aware waiting. `hash` and `randomHash` create deterministic or random identifiers. `checksum` provides SHA-256 integrity for structured values and raw bytes; structured values use stable key ordering unless `{ stable: false }` preserves a legacy byte layout. `noop` is the shared no-op.

## State directories

`directories(folderName)` returns a lazy handle under `process.cwd()/.basis/<folderName>`. Its `json(filename)` form reads parsed JSON or returns `null` only when the file is absent; `json(filename, content, options)` writes atomically and returns the content. Directory paths reject absolute and traversal segments. `path` is available for binary files, and `file(filename)` ensures the directory before returning a file path.

```ts
import { directories } from 'basis/utilities'

const database = directories('database')
const state = await database.json('cutover.json')
await database.json('cutover.json', { phase: 'prepared' }, { mode: 0o600 })
```

## URI and runtime

`parseURI`, `parseTemplateURI`, `match`, and `matchTemplateURI` power server routing. `HttpVerb` enumerates HTTP methods. `BasisRuntime` helpers (`EMPTY_BASIS_RUNTIME`, `parseBasisRuntime`, `serializeBasisRuntime`) carry server facts into the SPA shell.

## Types

The index exports `BasisRuntime`, `FrontMatterParts`, `ILogger`, `LoggerContext`, `LoggerOptions`, `PathOf`, `Primitive`, `TypeAt`, and `URI`. `Logger` and its types are also available through the supported `basis/logger` surface.
