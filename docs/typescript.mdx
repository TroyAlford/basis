# TypeScript

Basis ships TypeScript presets and a Bun-native typecheck entry point:

```json
{
  "extends": "basis/tsconfig/bun.json"
}
```

Presets are `basis/tsconfig/base.json`, `basis/tsconfig/bun.json`, and `basis/tsconfig/react.json`. They contain no Basis-monorepo path mappings, so a consumer resolves only its own dependencies and the supported Basis facade.

`basis typecheck` runs Bun's built-in TypeScript checker, which requires Bun 1.4.3 or newer. `basis lint` and `basis compliance` use Bun's built-in linter and also run the typechecker; the linter requires a Bun build with `bun lint`. The full Basis Server install requires Bun 1.4.6 or the approved canary described in [Installation](./installation.mdx). The presets remain compatible with the TypeScript 6/7 syntax Basis supports.

```bash
bunx basis typecheck
bunx basis lint
bunx basis compliance
```

The install hook and `Server.start()` enforce the server runtime requirement; the typecheck command separately checks the built-in checker minimum. An older runtime reports the required version and installation method instead of silently running an unsupported checker or server.

`typecheck` runs the checker with the repository configuration. `lint` adds the style policy, and `compliance` adds the paradigm rules; both include typecheck. The presets target TS 6/7 and omit options removed in that release, such as `downlevelIteration`.
