# TypeScript

Basis ships TypeScript presets and a native typecheck entry point:

```json
{
  "extends": "basis/tsconfig/bun.json"
}
```

Presets are `basis/tsconfig/base.json`, `basis/tsconfig/bun.json`, and `basis/tsconfig/react.json`. They contain no Basis-monorepo path mappings, so a consumer resolves only its own dependencies and the supported Basis facade.

The repository targets TypeScript 7 (the native compiler). The workspace also installs a TypeScript 6 API package for tooling that still requires the programmatic API, such as typescript-eslint.

```bash
bunx basis typecheck
bunx basis check
```

`typecheck` runs the native compiler with the repository configuration. `check` includes typecheck plus the repository's broader validation set. The presets target TS 6/7 and omit options removed in that release, such as `downlevelIteration`.
